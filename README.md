# Sneakers Sales Analysis

A learning project exploring sneaker store data through data modeling, SQL, Python, and Power BI.

The project brings together database design, data analysis, and dashboard reporting, with documentation organized into four sections.

## Tools Used

- SQL
- Python and Pandas
- Power BI
- Entity Relationship Diagrams (ERD)

## Explore the Project

### 1. Data Modeling
Database structure, table relationships, and the design of the sneaker store data model.

[View Data Modeling](Data_Modeling.pdf)

### 2. SQL Analysis
SQL queries exploring customers, orders, and products, using filtering, joins, and aggregations.

[View SQL Analysis](SQL_Analysis.pdf)

### 3. Python Analysis
Data exploration and analysis using Python and Pandas, documented through code screenshots, outputs, and conclusions.

[View Python Analysis](Python_Analysis.pdf)

### 4. Power BI Dashboard
A visual report presenting the analysis through charts and summary metrics.

[View Power BI Dashboard](Power_BI_Dashboard.pdf)

## About the Files

The project documentation is provided in PDF format for easy viewing. Explanations are primarily in Hebrew, alongside code and technical terms in English.

The Power BI PDF is a static export; interactive filters are not available in this version.
